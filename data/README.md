
# Noise Dataset

This project uses four noise conditions:
- White noise
- Kitchen noise
- Traffic noise
- Public-space noise

The environmental recordings were obtained from the
DEMAND dataset.

The full noise recordings are not included in this
repository because of their size.

To reproduce the experiments, download the required
recordings from the Research_Project_Code_520407080 file, which are in the folder noise.

See the main project README for preprocessing and
experimental settings.
