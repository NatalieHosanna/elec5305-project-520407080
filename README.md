ELEC5305 project investigating speech enhancement algorithms under different background noise conditions.

## Evaluation of Speech Enhancement Algorithms Under Different Background Noise Conditions
This project investigates how different speech enhancement algorithms perform under different types and levels of background noise.

The project will compare spectral subtraction and Wiener filtering using speech signals affected by noise such as white noise, traffic noise and cafe noise. Performance will be evaluated using methods such as SNR improvement and spectrogram analysis and implemented in MATLAB.
